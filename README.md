# 🚀 JavaScript Project-Based Revision

A collection of mini JavaScript projects built to revise and strengthen core frontend development concepts using **HTML**, **CSS**, and **Vanilla JavaScript**.

---

## 📁 Projects

### 1. 🔢 Counter
A simple counter app to practice DOM manipulation and event handling.

**Concepts Covered:**
- DOM selection & manipulation
- Event listeners (`click`)
- Increment / Decrement / Reset logic

---

### 2. ✅ To-Do App
A task management app to add, complete, and delete tasks.

**Concepts Covered:**
- Dynamic DOM creation
- Array-based state management
- LocalStorage (data persistence)
- Event delegation

---

### 3. 📝 Notes App
A note-taking app that allows users to create and manage notes.

**Concepts Covered:**
- CRUD operations in the browser
- `contenteditable` or textarea-based input
- LocalStorage for saving notes
- Dynamic rendering

---

### 4. 🌤️ Weather App
A weather application that fetches real-time weather data for any city.

**Concepts Covered:**
- Fetch API & `async/await`
- OpenWeatherMap API integration
- JSON data parsing
- Dynamic UI updates based on API response

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML | Structure / Markup |
| CSS | Styling & Layout |
| JavaScript (Vanilla) | Logic & Interactivity |
| Fetch API | Weather data fetching |

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/choudhry64/Javascript-project-based-revision.git
   ```

2. Navigate to any project folder:
   ```bash
   cd counter
   ```

3. Open `index.html` directly in your browser — no build tools or setup needed!

> **Note:** For the Weather App, you'll need a free API key from [OpenWeatherMap](https://openweathermap.org/api). Add your key in the `script.js` file.
